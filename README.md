# Number Merge

**Android puzzle game built iteratively with Codex**

Number Merge is a compact number-merging puzzle game developed as a real-world experiment in AI-assisted software creation.

I am not a professional software developer. The project was designed, implemented, tested and iterated with the help of **ChatGPT and Codex**, from game rules and balancing to Android packaging and external beta testing.

## The game

The board contains **5 columns × 7 rows**.

Players drop numbered blocks and create increasingly valuable blocks by merging matching neighbours.

The project focuses on:
- simple rules with emergent strategy;
- cascading merges;
- progressive difficulty;
- mobile usability;
- score chasing and replayability;
- iterative balancing based on real playtests.
